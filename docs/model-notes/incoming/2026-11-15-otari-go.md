# Otari Go joins the OpenCode lanes

2026-11-15. Setup notes and one smoke result, not a model ranking.

## Routing

- **Otari Go is its own flat-rate lane** (`otari/<selector>`, e.g. `otari/z-ai/glm-5.3`), separate from OpenCode Go (`opencode-go/*`). Separate credential, separate endpoint (`api.otari.ai/api/v1`), separate Access label on the scoreboard.
- $10/mo buys a $30 monthly allowance on covered open-weight models. The plan allows only 3 parallel requests: keep Otari lanes to 3 or fewer at once.
- Otari does not publish which models the plan covers. Watch the dashboard before leaning on it.

## otari/z-ai/glm-5.3 (OpenCode)

- 2026-11-15 — docs smoke (`otari-go-smoke`, lane `otari-glm53`): one-attempt PASS, 6.1 s. The run before it failed in 2 s on a 401 because the key was not yet in OpenCode's credential store. That FAIL is a setup fault, not the model's.

## Orchestrator lessons

- **OpenCode 2.3 ignores `auth.json` for custom providers.** Store the key with `opencode auth import` (integrationID `otari`); `opencode auth list` should then show "Otari".
- **OpenCode 2.3 no longer emits `"tokens":{"total":N}`.** Step events now carry `input`/`output`/`reasoning`/`cache`, so `token_regex` misses and every OpenCode lane reads "—" for tokens.
