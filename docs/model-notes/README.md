# Model notes inbox

Each session records new model judgments in its own Markdown file under `incoming/`.
Use the same shape as `docs/MODEL-NOTES.md`: level-2 `## <model or section>`
headings with dated `- 2026-01-01 — ...` bullets. Incoming entries are merged into
the model scoreboard automatically. Periodically, a human curator folds reviewed
entries into the canonical `docs/MODEL-NOTES.md` log.
